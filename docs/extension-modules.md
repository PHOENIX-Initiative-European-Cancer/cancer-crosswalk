# Extension modules — inverse gaps (source-side, no ECCDM hub home)

Generated by `scripts/inverse_gaps.py`. Every source element that maps
to NO ECCDM hub element, clustered into candidate extension modules and
classified by how ECCDM could carry it.

- **coded-finding** — the terminology carries the meaning: a generic coded Condition/Observation attached by evidence reference suffices.
- **extend-model** — attribute-level detail of a model ECCDM already has (CancerStage, SystemicTreatment, Radiotherapy, Surgery, LastFollowUp).
- **new-module** — needs a whole new hub model, either because the hub has no counterpart or because the meaning needs structure (method, score, side) that a code alone cannot carry.
- **out-of-scope** — administrative, registry transport, other-entity organ modules, genomics infrastructure: not clinical content ECCDM targets.
- **review** — structural leaves whose context was lost in extraction.
