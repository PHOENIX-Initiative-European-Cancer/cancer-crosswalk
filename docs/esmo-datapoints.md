Columns: *hub home* = best predicate of the SSSOM rows (exact/close = the hub carries it; narrow/broad = the hub carries a coarser or finer concept; related = derivable from hub elements; none = no hub element). *carriage* classifies the data points the hub does not carry, using the classes of `docs/extension-modules.md` plus `derived` (computable from hub elements) and `process`. *INT* = availability of the mapped hub element in the INT Milan workbook. *standards* = which of oBDS / NABON / B1MG / Senologie map to that hub element (from the existing SSSOM sets), and, for every row, which source element lists match the row's keyword probe (`probe:` column, hit counts; a count is a lead, not a mapping).

## Reading the probe counts

The probe is a per-row regular expression run over each source's element list (element path, label, definition); it is a lead for the curator, not a mapping. Zero hits in every column means none of the five sources names the concept; hits in INT come from its 68 ECCDM-attribute rows and 276 local code labels, so INT can only hit items that ECCDM itself has.
